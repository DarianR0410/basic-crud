# Gestor de Tareas (CRUD)

Proyecto de la Tarea 3 - Uso de Git y Git Flow.

Aplicacion de consola en Node.js que implementa un CRUD completo
(los datos se guardan en `tareas.json`):

- **Create**: crear una tarea
- **Read**: listar tareas
- **Update**: actualizar titulo y estado
- **Delete**: eliminar una tarea

## Requisitos
- Node.js 18 o superior (no requiere instalar librerias)

## Ejecucion
```bash
node app.js
```
o bien `npm start`.

## Ramas
- `main`: produccion
- `qa`: pruebas
- `develop`: integracion
- `feature/*` y `hotfix/*`: trabajo individual
